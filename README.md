## File Structure & Placement
This repository is organized to make launching your modding profiles as seamless as possible.
Below is a breakdown of what each folder is used for:

- [**Executables folder**](executables): Contains pre-configured executable files (`.exe`)
designed for easy integration with **Steam**. Add these executables to your **Steam** library
as `non-Steam` games. This allows you to launch specific modding profiles directly through
your **Steam** client with a single click.
- [**Resources folder**](resources): Holds custom **Steam** media assets to visually
personalize your mod profiles. Use the artwork found here within your **Steam** client to
give each mod profile its own look.
- [**Mods folder**](mods): Drop your primary mod files here to activate them in-game.
- [**Regulations folder**](regulations): Contains `regulation.bin` files that apply
game balance, stat tweaks, or modded parameters.

> [!NOTE]
> To play the vanilla games without any modifications, just launch **Elden Ring**
> or **Elden Ring NightReign** directly through **Steam**.
